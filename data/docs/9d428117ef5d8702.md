**Applies to:**  Databricks SQL  Databricks Runtime

This article presents links to and descriptions of built-in operators and functions for strings and binary types, numeric scalars, aggregations, windows, arrays, maps, dates and timestamps, casting, CSV data, JSON data, XPath manipulation, and other miscellaneous functions.

For use cases that are not supported by existing built-in functions, consider defining a custom function. See [What are user-defined functions (UDFs)?](/aws/en/udf/).

Also see:

* [Alphabetical list of built-in functions](/aws/en/sql/language-manual/sql-ref-functions-builtin-alpha)

## Operators and predicates

For information on how operators are parsed with respect to each other, see [Operator precedence](#operator-precedence).

| Operator | Syntax | Description |
| --- | --- | --- |
| [&](/aws/en/sql/language-manual/functions/ampersandsign) | `expr1 & expr2` | Returns the bitwise `AND` of `expr1` and `expr2`. |
| [and](/aws/en/sql/language-manual/functions/and) | `expr1 and expr2` | Returns the logical `AND` of `expr1` and `expr2`. |
| [\*](/aws/en/sql/language-manual/functions/asterisksign) | `multiplier * multiplicand` | Returns `multiplier` multiplied by `multiplicand`. |
| [!=](/aws/en/sql/language-manual/functions/bangeqsign) | `expr1 != expr2` | Returns true if `expr1` does not equal `expr2`, or `false` otherwise. |
| [!](/aws/en/sql/language-manual/functions/bangsign) | `!expr` | Returns the logical `NOT` of a Boolean expression. |
| [between](/aws/en/sql/language-manual/functions/between) | `expr1 [not] between expr2 and expr3` | Tests whether `expr1` is greater or equal than `expr2` and less than or equal to `expr3`. |
| [[]](/aws/en/sql/language-manual/functions/bracketsign) | `arrayExpr [ indexExpr ]` | Returns `indexExpr`nd element of `ARRAY` `arrayExpr`. |
| [[]](/aws/en/sql/language-manual/functions/bracketsign) | `mapExpr [ keyExpr ]` | Returns value at `keyExpr` of `MAP` `mapExpr`. |
| [^](/aws/en/sql/language-manual/functions/caretsign) | `expr1 ^ expr2` | Returns the bitwise exclusive `OR (XOR)` of `expr1` and `expr2`. |
| [:](/aws/en/sql/language-manual/functions/colonsign) | `jsonStr : jsonPath` | Returns fields extracted from the `jsonStr`. |
| [::](/aws/en/sql/language-manual/functions/coloncolonsign) | `expr :: type` | Casts the value `expr` to the target data type `type`. |
| [?::](/aws/en/sql/language-manual/functions/questiondoublecolonsign) | `expr ?:: type` | Casts the value `expr` to the target data type `type` if possible, returns `NULL` otherwise. |
| [div](/aws/en/sql/language-manual/functions/div) | `dividend div divisor` | Returns the integral part of the division of `dividend` by `divisor`. |
| [.](/aws/en/sql/language-manual/functions/dotsign) | `mapExpr . keyIdentifier` | Returns a `MAP` value by `keyIdentifier`. |
| [.](/aws/en/sql/language-manual/functions/dotsign) | `structExpr . fieldIdentifier` | Returns a `STRUCT` field by `fieldIdentifier`. |
| [==](/aws/en/sql/language-manual/functions/eqeqsign) | `expr1 == expr2` | Returns `true` if `expr1` equals `expr2`, or `false` otherwise. |
| [=](/aws/en/sql/language-manual/functions/eqsign) | `expr1 = expr2` | Returns `true` if `expr1` equals `expr2`, or `false` otherwise. |
| [>=](/aws/en/sql/language-manual/functions/gteqsign) | `expr1 >= expr2` | Returns `true` if `expr1` is greater than or equal to `expr2`, or `false` otherwise. |
| [>](/aws/en/sql/language-manual/functions/gtsign) | `expr1 > expr2` | Returns `true` if `expr1` is greater than `expr2`, or `false` otherwise. |
| [>>](/aws/en/sql/language-manual/functions/gtgtsign) | `expr >> n` | Returns `expr` bitwise signed right shifted by `n` bits. |
| [>>>](/aws/en/sql/language-manual/functions/gtgtgtsign) | `expr >>> n` | Returns `expr` bitwise unsigned right shifted by `n` bits. |
| [exists](/aws/en/sql/language-manual/functions/exists) | `exists(query)` | Returns true if `query` returns at least one row, or false otherwise. |
| [ilike](/aws/en/sql/language-manual/functions/ilike) | `str [not] ilike (pattern[ESCAPE escape])` | Returns true if `str` does (not) match `pattern` with `escape` case-insensitively. |
| [ilike](/aws/en/sql/language-manual/functions/ilike) | `str [not] ilike {ANY|SOME|ALL}([pattern[, ...]])` | Returns true if `str` does (not) match any/all patterns case-insensitively. |
| [in](/aws/en/sql/language-manual/functions/in) | `elem [not] in (expr1[, ...])` | Returns `true` if `elem` does (not) equal any `exprN`. |
| [in](/aws/en/sql/language-manual/functions/in) | `elem [not] in (query)` | Returns `true` if `elem` does (not) equal any row in `query`. |
| [is distinct](/aws/en/sql/language-manual/functions/isdistinct) | `expr1 is [not] distinct from expr2` | Tests whether the arguments do (not) have different values where `NULL`s are considered as comparable values. |
| [is false](/aws/en/sql/language-manual/functions/isfalse) | `expr is [not] false` | Tests whether `expr` is (not) `false`. |
| [is null](/aws/en/sql/language-manual/functions/isnull) | `expr is [not] null` | Returns `true` if `expr` is (not) `NULL`. |
| [is true](/aws/en/sql/language-manual/functions/istrue) | `expr is [not] true` | Tests whether `expr` is (not) `true`. |
| [like](/aws/en/sql/language-manual/functions/like) | `str [not] like (pattern[ESCAPE escape])` | Returns true if `str` does (not) match `pattern` with `escape`. |
| [like](/aws/en/sql/language-manual/functions/like) | `str [not] like {ANY|SOME|ALL}([pattern[, ...]])` | Returns true if `str` does (not) match any/all patterns. |
| [<=>](/aws/en/sql/language-manual/functions/lteqgtsign) | `expr1 <=> expr2` | Returns the same result as the `EQUAL(=)` for non-null operands, but returns `true` if both are `NULL`, `false` if one of the them is `NULL`. |
| [<=](/aws/en/sql/language-manual/functions/lteqsign) | `expr1 <= expr2` | Returns `true` if `expr1` is less than or equal to `expr2`, or `false` otherwise. |
| [<>](/aws/en/sql/language-manual/functions/ltgtsign) | `expr1 <> expr2` | Returns `true` if `expr1` does not equal `expr2`, or `false` otherwise. |
| [<](/aws/en/sql/language-manual/functions/ltsign) | `expr1 < expr2` | Returns `true` if `expr1` is less than `expr2`, or `false` otherwise. |
| [<<](/aws/en/sql/language-manual/functions/ltltsign) | `expr << n` | Returns `expr` bitwise left shifted by `n` bits. |
| [-](/aws/en/sql/language-manual/functions/minussign) | `expr1 - expr2` | Returns the subtraction of `expr2` from `expr1`. |
| [not](/aws/en/sql/language-manual/functions/not) | `not expr` | Returns the logical `NOT` of a Boolean expression. |
| [or](/aws/en/sql/language-manual/functions/or) | `expr1 or expr2` | Returns the logical `OR` of `expr1` and `expr2`. |
| [%](/aws/en/sql/language-manual/functions/percentsign) | `dividend % divisor` | Returns the remainder after `dividend` / `divisor`. |
| [||](/aws/en/sql/language-manual/functions/pipepipesign) | `expr1 || expr2` | Returns the concatenation of `expr1` and `expr2`. |
| [|](/aws/en/sql/language-manual/functions/pipesign) | `expr1 | expr2` | Returns the bitwise `OR` of `expr1` and `expr2`. |
| [+](/aws/en/sql/language-manual/functions/plussign) | `expr1 + expr2` | Returns the sum of `expr1` and `expr2`. |
| [regexp](/aws/en/sql/language-manual/functions/regexp) | `str [not] regexp regex` | Returns true if `str` does (not) match `regex`. |
| [regexp\_like](/aws/en/sql/language-manual/functions/regexp_like) | `str [not] regexp_like regex` | Returns true if `str` does (not) match `regex`. |
| [rlike](/aws/en/sql/language-manual/functions/rlike) | `str [not] rlike regex` | Returns true if `str` does (not) match `regex`. |
| [/](/aws/en/sql/language-manual/functions/slashsign) | `dividend / divisor` | Returns `dividend` divided by `divisor`. |
| [~](/aws/en/sql/language-manual/functions/tildesign) | `~ expr` | Returns the bitwise `NOT` of `expr`. |
