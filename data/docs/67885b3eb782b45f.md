Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page by opting into the **Notion connector** preview. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Notion connector in Lakeflow Connect ingests pages, data sources, databases, blocks, comments, and users from Notion into Databricks.

## Ingest from Notion in 3 steps

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Notion for ingestion](/aws/en/ingestion/lakeflow-connect/notion-source-setup)** (Administrators) — Register a Notion public integration so Databricks can authenticate.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/notion-connection)** (Administrators) — Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Notion, and select the pages and data sources to share.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/notion-pipeline)** (Administrators or non-administrators) — Select any supported interface and create a pipeline from an existing connection.
