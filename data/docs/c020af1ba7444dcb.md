Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Amplitude connector in Lakeflow Connect ingests product analytics event data along with event, cohort, and annotation metadata from Amplitude into Databricks.

## Ingest from Amplitude in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Amplitude for ingestion](/aws/en/ingestion/lakeflow-connect/amplitude-source-setup)** (Admins): Set up Amplitude to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/amplitude-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Amplitude.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/amplitude-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
