Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Akamai WAF** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Akamai WAF connector in Lakeflow Connect ingests web application firewall (WAF) security events from the Akamai Security Information and Event Management (SIEM) API into Databricks.

## What to know before you start

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

## Start ingesting from Akamai

1. **[Configure Akamai for ingestion](/aws/en/ingestion/lakeflow-connect/akamai-waf-source-setup)** (Admins). Set up Akamai to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/akamai-waf-connection)** (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/akamai-waf-pipeline)** (Admins or non-admins). Select any supported interface and create a pipeline from an existing connection.
