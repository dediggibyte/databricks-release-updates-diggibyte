Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Productboard** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Productboard connector in Lakeflow Connect ingests product hierarchy, roadmap, objectives, customer feedback notes, and workspace member data from Productboard into Databricks.

## Ingest from Productboard in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Productboard for ingestion](/aws/en/ingestion/lakeflow-connect/productboard-source-setup)** (Admins): Set up Productboard to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/productboard-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Productboard.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/productboard-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
