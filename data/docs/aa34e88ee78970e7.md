Genie One can perform more complex work beyond SQL, including more advanced analyses and document types. Code runs on your behalf in a secure, isolated sandbox using your existing permissions, so Unity Catalog governance and data access controls continue to apply. Before it runs code, Genie One confirms that the code matches your request.

For example, it can:

* Run advanced analyses, such as statistical analysis, forecasting, and what-if scenarios.
* Work with data from [files you upload](/aws/en/genie-one/chat#upload-a-file), such as CSV and Excel files.

Tell Genie One to do this for you:

```
From the sales data in this chat, forecast revenue for the next four quarters and chart the trend.
```

## Permissions and governance

Code execution doesn't grant any new permissions. Because code runs as you, what Genie One can do with it depends on the data access and [entitlements](/aws/en/security/auth/entitlements) you already have. If a request falls outside your permissions, Genie One stops and explains why.

## Code execution in scheduled tasks

Because [scheduled tasks](/aws/en/genie-one/chat#scheduled-tasks) run when you aren't present, they handle code execution differently:

* Code execution is allowed by default. Describe what the task is allowed to do in the task instructions.
* On each run, Genie One checks the generated code against those instructions. If the code is consistent with the instructions, Genie One runs it. If it can't confirm that the code matches, it declines to run the code.

## Billing

Code execution runs on serverless compute and is billed as sandbox usage.
