Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Asana** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Asana connector in Lakeflow Connect ingests work management data such as workspaces, projects, tasks, portfolios, and goals from Asana into Databricks.

## Feature availability

| Feature | Availability |
| --- | --- |
| UI-based pipeline authoring | Supported |
| API-based pipeline authoring | Supported |
| Declarative Automation Bundles | Supported |
| Incremental ingestion | Not supported  The connector reingests all records in every table on each pipeline update. |
| Unity Catalog governance | Supported |
| Orchestration using Lakeflow Jobs | Supported |
| API-based column selection and deselection | Supported |
| API-based row filtering | Not supported |
| Slowly changing dimension (SCD) type 2 | Not supported  All tables are ingested as full-refresh snapshots with no change tracking, so SCD type 2 isn't available. |
| Automated schema evolution: New and deleted columns | Supported |
| Automated schema evolution: Data type changes | Not supported |
| Automated schema evolution: Column renames | Not supported  Requires a full refresh. |

## Ingest from Asana in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Asana for ingestion](/aws/en/ingestion/lakeflow-connect/asana-source-setup)** (Admins): Set up Asana to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/asana-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Asana.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/asana-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
