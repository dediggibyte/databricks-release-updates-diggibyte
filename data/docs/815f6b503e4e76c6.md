Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Microsoft 365 Unified Audit Logs** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Microsoft 365 Unified Audit Logs connector in Lakeflow Connect ingests unified audit events from Microsoft Entra ID, Exchange, SharePoint, and other Microsoft 365 workloads into Databricks.

The connector uses the [Microsoft 365 Management Activity API](https://learn.microsoft.com/office/office-365-management-api/office-365-management-activity-api-reference) to ingest append-only audit events. It doesn't ingest Outlook messages or SharePoint files.

note

## Start ingesting from Microsoft 365

1. **[Configure Microsoft 365 for ingestion](/aws/en/ingestion/lakeflow-connect/microsoft-365-source-setup)** (Microsoft 365 and Entra admins). Enable unified auditing and create a Microsoft Entra application for Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/microsoft-365-connection)** (Admins). Create a connection in Catalog Explorer so pipeline authors don't need direct access to the credentials.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/microsoft-365-pipeline)** (Admins or non-admins). Use Declarative Automation Bundles or a Databricks notebook to create a pipeline from an existing connection.
