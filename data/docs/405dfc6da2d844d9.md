Upload CSV, Excel, and PDF files directly into a Genie Agent so users can query them in natural language alongside Unity Catalog tables.

note

Genie Agents were formerly known as Genie Spaces.

## Overview

Uploading files to a Genie Agent allows you to explore data in a Genie Agent conversation. You can add files to agents that also include Unity Catalog tables, making it possible to analyze uploaded data alongside existing sources. Instead of manually importing and transforming datasets, you can drag and drop a file into the chat and begin querying it immediately. This is useful for quick data validation, lightweight analysis, and working with external datasets without additional setup.

To let an agent answer questions across unstructured files stored in Unity Catalog volumes instead of uploading a file to a single conversation, see [Analyze files in volumes with a Genie Agent](/aws/en/genie-agents/volumes).

## Requirements

* Genie Agents must be enabled in your workspace. See [Create and manage a Genie Agent](/aws/en/genie-agents/set-up).
* The **Upload data using the UI** workspace admin setting must be enabled. See [Disable the upload data UI](/aws/en/admin/workspace-settings/disable-upload-data-ui).
* To upload PDF files, partner-powered AI features must be enabled. See [Partner-powered AI features](/aws/en/databricks-ai/partner-powered).
* At least CAN VIEW permissions on the Genie Agent. See [Genie Agent ACLs](/aws/en/security/auth/access-control/#genie-agent-acls).

## File requirements

You can upload up to 25 files per conversation, regardless of file type.

### CSV and Excel files

The following requirements apply to CSV and Excel file uploads:

* Each file must be smaller than 200 MB.
* Each file must contain fewer than 100 columns.
* Excel files can contain multiple sheets. Genie displays sample data from the first sheet by default, but all sheets that can be parsed are available. To query a specific sheet, reference it by name when asking Genie.

### PDF files

PDF uploads require Agent mode, a multi-step reasoning mode for complex, exploratory questions. See [Agent mode](/aws/en/genie-agents/concepts#agent-mode).

* Each PDF must be smaller than 20 MB.
* Each PDF must contain no more than 100 pages.
* Each PDF is limited to 15,000 characters.
* Uploaded PDFs apply only to the current conversation. New chat threads do not include context from previously uploaded PDFs.
* PDF uploads are only available through the UI. API-based file uploads are not supported.

## Upload a file

Only the user who uploaded the file can access it.

Upload files in one of the following ways:

* Drag and drop the file into the chat window.
* Click  to select a file from your file browser.

Uploading a file no longer sends a message automatically. You can add a prompt to send with the file, or upload the file and then ask questions about it. After the file is uploaded and processed, Genie displays the data in the response. You can ask questions about the uploaded file and any other data in the Genie Agent.

note

Uploaded files are stored in a user- and agent-specific Unity Catalog managed volume. The volume is not listable and does not appear in the schema browser. Permissions on uploaded files do not need to be managed manually. Users are automatically granted USE CATALOG, USE SCHEMA, READ VOLUME, and WRITE VOLUME privileges on their uploaded files.

Databricks stores uploaded files in customer-managed root storage on classic workspaces and in [default storage](/aws/en/storage/default-storage) on serverless workspaces.

For more information about managed volumes, see [What are Unity Catalog volumes?](/aws/en/volumes/).

## View available files

To view files that have been uploaded to the agent, click  to open the file menu. If an uploaded Excel file has multiple sheets, they appear as separate files in the menu.

## Adjust file format settings

To adjust the formatting settings applied to a file:

1. Click  to open the file menu.
2. Click  the wrench icon to the right of the file.
3. Adjust settings in the **File Format Settings** dialog.
4. Click **Apply changes** to preview your changes.
5. Click **Save** to keep your changes and close the dialog.

## Remove a file

Files uploaded to a Genie Agent have no fixed retention period. They remain available until one of the following happens:

* The user removes the file by clicking  the trash icon next to the file in the attached files menu.
* The conversation is deleted.
* The Genie Agent is deleted. Files are automatically removed from managed storage when the agent is deleted.

## Disable file uploads

A workspace admin can prevent the ability to upload files to a Genie Agent. To do so, turn off **Upload data using the UI**. See [Disable the upload data UI](/aws/en/admin/workspace-settings/disable-upload-data-ui).

## FAQ

### Who can access uploaded files?

Only the user who uploaded the file can access it.

### What data is sent to the LLM?

A subset of the data from uploaded files is sent to the external model and used to improve the response quality and properly parse the files.

### Why can't I upload a file?

The **Upload data using the UI** workspace setting might be turned off for your workspace. See [Disable the upload data UI](/aws/en/admin/workspace-settings/disable-upload-data-ui).

If you are getting the error message **Could not prepare volume for file uploading**, your workspace admin might need to address a storage location conflict. See [Resolve storage path conflicts](/aws/en/data-governance/unity-catalog/storage-conflicts).
