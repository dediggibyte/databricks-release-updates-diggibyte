Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Shopify** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Shopify connector in Lakeflow Connect ingests e-commerce data such as products, orders, customers, inventory, fulfillments, and discounts from Shopify into Databricks.

## Ingest from Shopify in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

## Start ingesting from Shopify

1. **[Configure Shopify for ingestion](/aws/en/ingestion/lakeflow-connect/shopify-source-setup)** (Admins): Set up Shopify to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/shopify-connection)** (Admins): Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/shopify-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
