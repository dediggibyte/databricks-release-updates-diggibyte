Legacy agent offerings are earlier Databricks agent products that are no longer best practice for building agents. They remain documented so that you can maintain and migrate existing agents. Don't use them for new agents. For how Databricks defines support lifecycles, see [Databricks support lifecycles](/aws/en/release-notes/runtime/databricks-runtime-ver).

For new agents written in code, Databricks recommends the [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli), which serves your agent with [`DurableAgentServer`](/aws/en/agents/deploy/agent-server) and deploys it to [Agent Runtime](/aws/en/agents/deploy/agent-runtime). See [Deploy agents on Databricks](/aws/en/agents/deploy/). For new agents built without code, use [Genie Agents](/aws/en/genie-agents/).

## Legacy offerings and their replacements

| Legacy offering | Use instead |
| --- | --- |
| [Knowledge Assistant](/aws/en/agents/agent-bricks/knowledge-assistant) | [Genie Agents](/aws/en/genie-agents/) for low-code agents over your documents and data. |
| [Supervisor Agent](/aws/en/agents/agent-bricks/multi-agent-supervisor) | [Genie Agents](/aws/en/genie-agents/) for low-code agents. To coordinate multiple agents in code, use the [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli). |
| [Supervisor API](/aws/en/agents/agent-bricks/supervisor-api) (deprecated) | Write your own agent loop and deploy it with the [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli). See [Deploy agents on Databricks](/aws/en/agents/deploy/). |
| [Build a custom multi-agent system](/aws/en/agents/custom-agents/multi-agent-apps) | The [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli). To give your agent Genie Agents as tools, run `agentbricks tools add genie-agent`. |
| [Run agents on Databricks Apps using the legacy agent server](/aws/en/agents/custom-agents/author-agent) | The [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli), with [`DurableAgentServer`](/aws/en/agents/deploy/agent-server) on [Agent Runtime](/aws/en/agents/deploy/agent-runtime). |
| [Create a chat agent front-end](/aws/en/agents/custom-agents/chat-app) | Projects that you create with the [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli) include a chat UI. |
| [Custom Agent on Model Serving](/aws/en/agents/custom-agents/model-serving/author-agent-model-serving) | The [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli). To move an existing agent, see [Migrate an agent from Model Serving to Databricks Apps](/aws/en/agents/custom-agents/migrate-agent-to-apps). |
| [Create a custom LLM agent](/aws/en/agents/agent-bricks/custom-llm) | [AI Functions](/aws/en/large-language-models/ai-functions), such as `ai_query`. |
| [Managed memory stores (legacy)](/aws/en/agents/agent-memory/managed-memory-stores) | [Managed agent memory](/aws/en/agents/agent-memory/managed-memory). |
| [AI Playground](/aws/en/large-language-models/ai-playground) | To query models, see [Query foundation and embedding models](/aws/en/ai-gateway/query-model-services). To build and test agents, use the [Agent Bricks CLI](/aws/en/agents/custom-agents/agent-bricks-cli) and run your agent locally with `agentbricks dev`. To query a deployed agent, see [Query agents deployed on Databricks](/aws/en/agents/query-llms). |
