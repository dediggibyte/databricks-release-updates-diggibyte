Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Microsoft Graph Logs** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Microsoft Graph Logs connector in Lakeflow Connect ingests security alerts from the Microsoft Graph security API into Databricks, including alerts from Microsoft Defender XDR and Microsoft Sentinel.

note

## Start ingesting from Microsoft Graph

1. [Configure Microsoft Graph for ingestion](/aws/en/ingestion/lakeflow-connect/microsoft-graph-logs-source-setup) (Admins). Set up Microsoft Graph to authenticate with Databricks.
2. [Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/microsoft-graph-logs-connection) (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. [Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/microsoft-graph-logs-pipeline) (Admins or non-admins). Select any supported interface and create a pipeline from an existing connection.
