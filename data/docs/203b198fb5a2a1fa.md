Add a Tableau or Power BI file to Genie Code and it builds an AI/BI dashboard that replicates your visualizations, connected to [metric views](/aws/en/dashboards/manage/data-modeling/local-metric-views) that mirror the underlying business logic. When migration tooling detects relationships in the source file, it also creates the corresponding [dashboard relationships](/aws/en/dashboards/manage/data-modeling/dashboard-relationships/) in the new dashboard. You can [import one file at a time](#upload-a-file) or [import multiple files in bulk](#bulk-import).

## Requirements

**Import from External BI to AI/BI** requires partner-powered AI features enabled for both the account and workspace. See [Partner-powered AI features](/aws/en/databricks-ai/partner-powered).

## Import one file at a time

You can import a Tableau or Power BI file (`.twb`, `.twbx`, `.tds`, `.tdsx`, `.pbit`, or `.tmdl`) by uploading it directly into the Genie Code chat or by referencing a file stored in a Unity Catalog volume. From a Tableau workbook (`.twb` or `.twbx`) or a Power BI report template (`.pbit`), Genie Code creates a dashboard and metric views. From a Power BI `.tmdl` file, it creates metric views. A Tableau data source file (`.tds` or `.tdsx`) supplies the data model for a workbook that uses a published data source. For help exporting files, see [Tableau export documentation](https://help.tableau.com/current/pro/desktop/en-us/export.htm) or [Power BI report templates](https://learn.microsoft.com/en-us/power-bi/create-reports/desktop-templates).

* Start from the dashboard list page
* Prompt

1. Click  **Dashboards** in the sidebar to open the dashboard list page.
2. Click the arrow next to **Create dashboard**, then select **Import from Tableau** or **Import from Power BI**.
3. Attach your Tableau or Power BI file.

This creates a new AI/BI dashboard and opens Genie Code to build it from your file.

1. Open Genie Code from [full page Genie Code](/aws/en/genie-code/navigate-genie-code#full-page) or from a draft AI/BI dashboard.
2. Ask Genie Code to import a Tableau or Power BI file, or type `/importBI`. In a draft dashboard, you can also click **Import from a BI tool** in a new chat.
3. Attach your file to the chat, or reference a file in a Unity Catalog volume by its path. For example:

   Text

   ```
   /importBI @/Volumes/my_catalog/my_schema/my_volume/sales_workbook.twb
   ```

When you start from full page Genie Code, it opens a new draft AI/BI dashboard and continues the import there.

note

Direct file uploads have a 100 MB size limit. For larger files, upload your file to a Unity Catalog volume first, then reference it by its path. You can also unzip a `.twbx` file and upload the extracted `.twb` file instead.

To import only the data model from a file, create a new, empty Unity Catalog metric view, open Genie Code, and type `/importBI`. See [Use Genie Code to import a Tableau or Power BI file](/aws/en/uc-semantics/metric-views/bi-tools#genie-code).

## Import multiple files in bulk

To migrate more than one report at a time, ask Genie Code to import your Tableau or Power BI files in a single request. Genie Code starts a separate background run for each file, and each run creates its own AI/BI dashboard and metric views. Because the runs happen in the background, you can close the browser tab or keep working while they finish.

1. Upload your Tableau or Power BI files to a Unity Catalog volume. Bulk import doesn't support direct file uploads to the chat. If a Tableau workbook uses a published data source, export the data source file (`.tds` or `.tdsx`) and upload it with the workbook.
2. Open Genie Code. You can start from [full page Genie Code](/aws/en/genie-code/navigate-genie-code#full-page), from the dashboard list page, or from a draft AI/BI dashboard.
3. Ask Genie Code to import the files. Either list each file path or name the volume that contains them. For example:

   Text

   ```
   Import all Tableau workbooks in /Volumes/main/bi_migration/tableau_files into AI/BI dashboards.
   ```

   You can also include instructions that apply to every file. For example, to migrate only the data models, ask Genie Code to create only the metric views.
4. Confirm the list of files that Genie Code finds. Genie Code automatically pairs each Tableau workbook (`.twb` or `.twbx`) with its related data source files. If Genie Code can't tell which files belong together, it asks you.
5. When prompted, enter the target Unity Catalog catalog and schema where Genie Code should create views, including metric views. Genie Code doesn't choose a default location for you.
6. Review the prompt and the list of files, then approve the bulk import to start the runs.

A bulk import can include between 2 and 100 files and supports the same file types as single-file import.

### Track a bulk import

After the bulk import starts, a **Bulk import started** card in the chat shows how many runs have finished and how many are in each status, such as completed, in progress, needing approval, or failed.

From the card, you can:

* Click a file name to open the Genie Code conversation for that run in a new tab, where you can review and refine the result.
* Click **Cancel run** to stop a single run, or **Cancel active runs** to stop all runs that are still active. Canceling doesn't affect runs that already completed.

To check progress later, reopen the chat where you started the bulk import from  **Chat history**, then ask Genie Code for the bulk import status. See [Work with multiple chats as tabs](/aws/en/genie-code/navigate-genie-code#tabs).

## Connect to your BI tool to improve migration quality

When you import a file, you can connect Genie Code to the Power BI or Tableau Cloud source the file comes from. Genie Code uses the connection to check the import against the live source. This feature is in Public Preview.

* **Power BI**: Genie Code runs read-only Data Analysis Expressions (DAX) queries against the live semantic model to check measures. Queries run with your Power BI permissions, and row-level security applies.
* **Tableau Cloud**: Genie Code checks measures against the live data source and checks each page against the live view's data and image. When a live view is available for every page, you don't need to upload screenshots.

To connect, add the Databricks-provided Power BI or Tableau connector to Genie Code. See [Use Databricks-provided MCP connectors for third-party sources](/aws/en/genie-code/mcp#connectors). The Tableau connector supports only Tableau Cloud. If the connection isn't available, Genie Code imports the file on its own.

## Promote metric views to Unity Catalog

The type of metric view that Genie Code creates for the measures and dimensions in your file depends on the source:

* **Power BI**: Genie Code creates Unity Catalog metric views, and reuses existing Unity Catalog metric views that already match your data model.
* **Tableau**: Genie Code creates local metric views scoped to the new dashboard, unless a matching Unity Catalog metric view already exists.

To override the default, tell Genie Code which type of metric view you want in your prompt. For example, ask Genie Code to create Unity Catalog metric views when you import a Tableau file.

Local metric views can be referenced only within the dashboard where they were created. Unity Catalog metric views are reusable across dashboards, Genie Agents, and notebooks, and get full Unity Catalog governance: access controls, lineage, and discoverability. Databricks recommends promoting local metric views to Unity Catalog after you finish iterating on them.

For instructions, see [Export to a Unity Catalog metric view](/aws/en/dashboards/manage/data-modeling/local-metric-views#export-to-uc).

## Best practices

Follow these practices to get the most accurate results when you migrate a BI file with Genie Code:

* **Always provide a screenshot**: Genie Code migrates best when it can validate layout and numbers against a high-quality reference image.
* **Expect to work with the agent conversationally**: Like any other agent, you can guide Genie Code and push back for better quality and accuracy.
* **Promote finished data models to Unity Catalog**: This lets future migrations that use the same or similar data models reuse your work. See [Promote metric views to Unity Catalog](#promote-to-uc).
* **Keep the browser tab open during a single-file import**: Don't close the tab or go to a different part of the workspace while Genie Code is running. This interrupts the migration agent and leaves an unfinished result. [Bulk imports](#bulk-import) run in the background and don't require an open tab.
