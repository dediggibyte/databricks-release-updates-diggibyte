Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Atlassian Audit Logs** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Atlassian Audit Logs connector in Lakeflow Connect ingests organization audit log events, such as user, security, and configuration changes, from Atlassian into Databricks.

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

## Start ingesting from Atlassian

1. **[Configure Atlassian for ingestion](/aws/en/ingestion/lakeflow-connect/atlassian-audit-logs-source-setup)** (Admins). Set up Atlassian to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/atlassian-audit-logs-connection)** (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/atlassian-audit-logs-pipeline)** (Admins or non-admins). Select any supported interface and create a pipeline from an existing connection.
