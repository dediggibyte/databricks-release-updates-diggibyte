Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Workday Activity Logging** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Workday Activity Logging connector in Lakeflow Connect ingests user activity log events from Workday into Databricks.

note

## Start ingesting from Workday

1. **[Configure Workday for ingestion](/aws/en/ingestion/lakeflow-connect/workday-activity-logging-source-setup)** (Admins). Enable activity logging and create an integration system user, security group, OAuth client, and refresh token.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/workday-activity-logging-connection)** (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/workday-activity-logging-pipeline)** (Admins or non-admins). Use Declarative Automation Bundles or a Databricks notebook to create a pipeline from an existing connection.
