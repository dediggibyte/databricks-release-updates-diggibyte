Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Glean connector in Lakeflow Connect ingests Glean insights and shortcuts data into Databricks. Insights provide company-wide usage summaries for search, Assistant, and agents. Shortcuts are the go links defined in your Glean deployment.

| --- | --- |

| OAuth M2M | Not supported |
| Basic authentication (username/password) | Not supported |

## Ingest from Glean in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

## Start ingesting from Glean

1. **[Configure Glean for ingestion](/aws/en/ingestion/lakeflow-connect/glean-source-setup)** (Admins). Set up Glean to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/glean-connection)** (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/glean-pipeline)** (Admins or non-admins). Select any supported interface and create a pipeline from an existing connection.
