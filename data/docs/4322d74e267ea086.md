Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Vimeo** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Vimeo connector in Lakeflow Connect ingests team, team member, team role, and audit log data from Vimeo into Databricks. It authenticates with a Vimeo personal access token, ingests `audit_logs` incrementally, and reingests the three team tables on every run.

## Ingest from Vimeo in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Vimeo for ingestion](/aws/en/ingestion/lakeflow-connect/vimeo-source-setup)** (Admins): Set up Vimeo to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/vimeo-connection)** (Admins): Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/vimeo-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
