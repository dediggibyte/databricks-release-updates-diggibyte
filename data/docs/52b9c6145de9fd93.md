Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed SendGrid connector in Lakeflow Connect ingests subuser directory data and IP access-management activity from SendGrid into Databricks.

## Ingest from SendGrid in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure SendGrid for ingestion](/aws/en/ingestion/lakeflow-connect/sendgrid-source-setup)** (Admins): Set up SendGrid to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/sendgrid-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with SendGrid.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/sendgrid-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
