This article describes the state-of-the-art open models that are supported by [Databricks Foundation Model APIs](/aws/en/machine-learning/foundation-model-apis/).

note

See [Model availability by region](/aws/en/unity-gateway/model-region-availability) for region availability of these models and the supported feature areas.

You can send query requests to these models using the pay-per-token endpoints available in your Databricks workspace. See [Use foundation models](/aws/en/machine-learning/model-serving/score-foundation-models) and [pay-per-token supported models table](/aws/en/machine-learning/foundation-model-apis/#token-foundation-apis) for the names of the model endpoints to use.

In addition to supporting models in pay-per-token mode, Foundation Model APIs also offers provisioned throughput mode. Databricks recommends provisioned throughput for production workloads. This mode supports all models of a model architecture family, including the fine-tuned and custom pre-trained models supported in pay-per-token mode. See [Provisioned throughput Foundation Model APIs](/aws/en/machine-learning/foundation-model-apis/#throughput) for the list of supported architectures.

You can interact with these supported models using the [AI Playground](/aws/en/large-language-models/ai-playground).

For OpenAI, Google Gemini, and Anthropic models, the context window and maximum output tokens match the values published by the respective model provider.

important

Customers are responsible for ensuring their compliance with [applicable model terms](/aws/en/machine-learning/model-serving/acceptable-use-models).

note

This model is not supported in [AI Playground](/aws/en/large-language-models/ai-playground). Use the [Responses API](/aws/en/machine-learning/model-serving/query-openai-responses) to interact with this model.

**Endpoint name**: `databricks-gpt-6-1-sol`

**Supported inputs**: text, image

GPT-6.1 Sol is an OpenAI general-purpose model for agentic coding, reasoning, and tool use. It supports text and image inputs.

For reasoning controls, see [Query reasoning models](/aws/en/machine-learning/model-serving/query-reason-models).

**Availability**: Pay-per-token. See [supported regions](/aws/en/unity-gateway/model-region-availability).
