Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Microsoft Entra ID** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Microsoft Entra ID connector in Lakeflow Connect ingests directory objects, role assignments, identity configuration, and audit and sign-in logs from Microsoft Entra ID into Databricks.

## Ingest from Microsoft Entra ID in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Microsoft Entra ID for ingestion](/aws/en/ingestion/lakeflow-connect/microsoft-entra-id-source-setup)** (Admins): Set up Microsoft Entra ID to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/microsoft-entra-id-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Microsoft Entra ID.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/microsoft-entra-id-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
