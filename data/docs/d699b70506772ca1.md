Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Google Workspace** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Google Workspace connector in Lakeflow Connect ingests audit activity from Google Workspace applications and services into Databricks.

## Ingest audit activity from Google Workspace

Set up the managed Google Workspace connector to ingest Google Workspace audit activity into Databricks.

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Google Workspace for ingestion](/aws/en/ingestion/lakeflow-connect/google-workspace-source-setup)** (Admins): Set up Google Workspace to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/google-workspace-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Google Workspace.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/google-workspace-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
