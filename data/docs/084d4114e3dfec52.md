### Work agents

Work agents are desktop applications, such as Claude desktop and ChatGPT desktop, for users who don't work in a terminal or IDE. `ug configure` sets them up along with Claude Code and the Codex CLI.

## Capability matrix

| Agent | Configured via Unity Gateway CLI | Databricks models | External providers | MCP servers | Skills | Setup |
| --- | --- | --- | --- | --- | --- | --- |
| Claude Code (CLI) | `ug claude` | Yes | Yes | Yes | Yes | [Claude Code](/aws/en/ai-gateway/coding-agent-claude) |
| Claude desktop (Work agent) | `ug configure --agents claude` | Yes | Yes | Yes | Yes | [Claude desktop](/aws/en/ai-gateway/coding-agent-claude-desktop) |
| Codex (CLI) | `ug codex` | Yes | Yes | Yes | Yes | [Codex](/aws/en/ai-gateway/coding-agent-codex) |
| ChatGPT desktop (Work agent) | `ug configure --agents codex` | Yes | Yes | Yes | Yes | [ChatGPT desktop](/aws/en/ai-gateway/coding-agent-chatgpt-desktop) |
| Cursor (IDE) | `ug mcp add --agents cursor` (MCP only) | Yes | — | Yes | Yes | [Cursor](/aws/en/ai-gateway/coding-agent-cursor) |
| Cursor Agent (CLI) | `ug cursor` (MCP only) | No | No | Yes | Yes | [Cursor](/aws/en/ai-gateway/coding-agent-cursor#cursor-agent-in-the-terminal) |
| GitHub Copilot CLI (CLI) | `ug copilot` | Yes | — | Yes | Yes | [GitHub Copilot CLI](/aws/en/ai-gateway/coding-agent-copilot) |
| Gemini CLI (CLI) | `ug gemini` | Yes | Yes (Gemini Enterprise) | Yes | Yes | [Gemini](/aws/en/ai-gateway/coding-agent-gemini) |
| OpenCode (CLI) | `ug opencode` | Yes | — | Yes | Yes | [OpenCode](/aws/en/ai-gateway/coding-agent-opencode) |
| Pi (CLI) | `ug pi` | Yes | — | No (Pi has no MCP client) | Yes | [Pi](/aws/en/ai-gateway/coding-agent-pi) |

Support varies by agent and version. Run `ug --help` to see supported agents. A `—` means this guide does not document setup for that capability. Follow the agent's link under **Setup** for configuration details.

Among work agents, Anthropic subscription relay is supported only in Claude desktop.
