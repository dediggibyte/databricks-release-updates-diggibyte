Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Google Analytics Aggregated** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Google Analytics Aggregated connector in Lakeflow Connect ingests aggregated Google Analytics 4 (GA4) report data, such as users, sessions, events, acquisition, ecommerce, and demographics metrics, from the Google Analytics Data API into Databricks. It also supports custom reports with the dimensions and metrics that you select.

note

To ingest raw, event-level GA4 data that Google Analytics exports to BigQuery, use the [Google Analytics Raw Data connector](/aws/en/ingestion/lakeflow-connect/google-analytics) instead.

## Ingest from Google Analytics in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Google Analytics for ingestion](/aws/en/ingestion/lakeflow-connect/google-analytics-aggregated-source-setup)** (Admins): Set up Google Analytics to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/google-analytics-aggregated-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Google Analytics.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/google-analytics-aggregated-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
