Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for Cribl** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Cribl connector in Lakeflow Connect ingests configuration, worker status, organization metadata, and Leader audit and access logs from Cribl.Cloud into Databricks.

## Ingest from Cribl.Cloud in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Cribl.Cloud for ingestion](/aws/en/ingestion/lakeflow-connect/cribl-source-setup)** (Admins): Set up Cribl.Cloud to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/cribl-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Cribl.Cloud.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/cribl-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
