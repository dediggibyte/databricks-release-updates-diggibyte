Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

To use the Celigo connector, a workspace admin must enable the **Lakeflow Connect - Celigo** preview on the **Previews** page.

The managed Celigo connector in Lakeflow Connect ingests audit log events, such as resource create, update, and delete operations, from Celigo into Databricks.

## Ingest from Celigo in three steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Celigo for ingestion](/aws/en/ingestion/lakeflow-connect/celigo-source-setup)** (Admins) — Set up Celigo to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/celigo-connection)** (Admins) — Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Celigo.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/celigo-pipeline)** (Admins or non-admins) — Select any supported interface and create a pipeline from an existing connection.
