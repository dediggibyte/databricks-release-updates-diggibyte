Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for PayPal** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed PayPal connector in Lakeflow Connect ingests payments data such as transactions, disputes, invoices, and balances from PayPal into Databricks.

## Ingest from PayPal in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure PayPal for ingestion](/aws/en/ingestion/lakeflow-connect/paypal-source-setup)** (Admins): Set up PayPal to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/paypal-connection)** (Admins): Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/paypal-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
