Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for QuickBooks** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed QuickBooks connector in Lakeflow Connect ingests accounting data such as accounts, customers, invoices, bills, and payments from QuickBooks into Databricks.

## Ingest from QuickBooks in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure QuickBooks for ingestion](/aws/en/ingestion/lakeflow-connect/quickbooks-source-setup)** (Admins): Set up QuickBooks to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/quickbooks-connection)** (Admins): Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/quickbooks-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
