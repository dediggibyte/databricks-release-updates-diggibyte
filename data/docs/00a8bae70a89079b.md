AI agents such as Claude, Claude Code, ChatGPT, Codex, and Cursor can call Databricks tools through Model Context Protocol (MCP) servers. Connect an agent to the [Genie One MCP server](/aws/en/agents/mcp-tools/genie-mcp) to ask questions about your data, or to [custom MCP servers](/aws/en/agents/mcp-tools/custom-mcp) that you build. Unity Catalog enforces your existing data permissions on each tool call.

AI agent partners connect through MCP servers instead of Partner Connect.

## Requirements

* [Permission to call the MCP](/aws/en/ai-gateway/govern-mcp-service#control-callers). For MCPs that use per-user OAuth, a [provider sign-in](/aws/en/ai-gateway/mcp-service-reference#provider-sign-in).
* The Consumer access or Workspace access entitlement. See [Use MCP tools with Consumer access](/aws/en/agents/mcp-tools/authentication-networking#consumer-access).

## Default OAuth client IDs

Databricks provides pre-created OAuth apps for AI agents. Use these client IDs to connect Claude on the desktop and web, Claude Code, ChatGPT on the desktop and web, Codex, and Cursor without asking an account admin to create or configure an OAuth app. These apps don't require a client secret.

| Agent | Client ID |
| --- | --- |
| Claude (desktop and web) | `https://claude.ai/oauth/mcp-oauth-client-metadata` |
| Claude Code | `https://claude.ai/oauth/claude-code-client-metadata` |
| ChatGPT (desktop and web) | `https://chatgpt.com/oauth/client.json` |
| Codex | `https://chatgpt.com/oauth/codex/client.json` |
| Cursor | `https://cursor.com/oauth/mcp-client.json` |

The client IDs are Client ID Metadata Document (CIMD) URLs. Enter the full URL as the client ID. Using OAuth also reduces reliance on long-lived personal access tokens (PATs).

An account admin can turn these apps on or off for the account. See [Enable AI assistant OAuth applications](/aws/en/integrations/enable-disable-oauth#ai-assistant-apps).

## Connect an AI agent

For setup steps, see your agent's guide:

* Claude: [Claude connectors](/aws/en/ai-gateway/coding-agent-claude#claude-connectors) or the [Claude desktop app](/aws/en/ai-gateway/coding-agent-claude#claude-desktop)
* Claude Code: [Claude Code](/aws/en/ai-gateway/coding-agent-claude#claude-code)
* ChatGPT: [Other MCP clients](/aws/en/ai-gateway/coding-agent-mcp-skills#other-mcp-clients)
* Codex: [Add MCP tools](/aws/en/ai-gateway/coding-agent-codex#add-mcp-tools)
* Cursor: [Add MCP tools](/aws/en/ai-gateway/coding-agent-cursor#add-mcp-tools)

To ask questions about your data from ChatGPT or Claude, you can also use the [Databricks Genie plugins](/aws/en/agents/mcp-tools/genie-mcp#genie-plugins).
