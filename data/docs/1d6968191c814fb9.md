The `ai_mask()` function uses an AI model to mask specified entities in a given text using SQL. Use it to redact sensitive values inside free text, such as support tickets, call transcripts, agent traces, and text extracted from documents, so the rest of the text stays usable.

To redact sensitive data in agent traces end to end, see [Govern and redact traces in Unity Catalog](/aws/en/mlflow3/genai/tracing/govern-redact).

## Version 1.0 vs. version 2.0

The function has two versions. Version 1.0 is the default. To use version 2.0, pass `options => map('version', '2.0')`. A call without that option runs version 1.0. If you pass classifier names without it, version 1.0 reads them as labels and returns `[MASKED]` text.

Version 2.0 differs from version 1.0 as follows:

* It masks sensitive data with a Databricks-built detection model. Version 1.0 uses a Llama chat model served by [Databricks Foundation Model APIs](/aws/en/machine-learning/foundation-model-apis/).
* It takes an optional list of system-defined classifiers, with an 18-classifier default set and 90 supported classifiers, listed under [Supported classifiers](#supported-classifiers). Version 1.0 takes free-text labels.
* It replaces each detected value with its classifier placeholder, such as `[NAME]`, and numbers several values of one classifier in a row, such as `[NAME_1]` and `[NAME_2]`. Version 1.0 replaces every detected value with `[MASKED]`.
* It returns a `VARIANT` that carries the masked text, the version, and a per-row error message. Version 1.0 returns a `STRING`. See Returns.

Version 2.0 is in [Beta](/aws/en/release-notes/release-types) and is available in the regions listed under Requirements. It isn't available on workspaces with the [compliance security profile](/aws/en/security/privacy/security-profile). Version 1.0 is in [Public Preview](/aws/en/release-notes/release-types) and [HIPAA compliant](/aws/en/security/privacy/hipaa#regional-support-for-features); use version 1.0 on those workspaces.

## Syntax

* Version 2.0
* Version 1.0

```
ai_mask(content [, classifiers], options => map('version', '2.0'))
```

```
ai_mask(content, labels [, options])
```

## Arguments

* Version 2.0
* Version 1.0

* `content`: A `STRING` expression.
* `classifiers`: Optional. An `ARRAY<STRING>` of classifier names such as `array('NAME', 'EMAIL_ADDRESS')`. Omit it, or pass `NULL`, to use the default set. Classifier names are case-insensitive. An explicitly empty array fails the query, and an unknown classifier name fails the query.
* `options`: A `MAP<STRING, STRING>` containing configuration options. Required for version 2.0:
  + `version`: Set to `"2.0"`. If you omit it, the function runs version 1.0, the default.

### Supported classifiers

The default classifier set applies when you pass no classifier list or `NULL`. It contains these 18 classifiers: `NAME`, `EMAIL_ADDRESS`, `PHONE_NUMBER`, `STREET_ADDRESS`, `DATE_OF_BIRTH`, `AGE`, `US_SSN`, `US_ITIN`, `PASSPORT`, `DRIVER_LICENSE`, `CREDIT_CARD`, `CARD_SECURITY_CODE`, `CARD_EXPIRATION_DATE`, `CARD_PIN`, `BANK_NUMBER`, `IBAN_CODE`, `IP_ADDRESS`, and `SECRET`.
