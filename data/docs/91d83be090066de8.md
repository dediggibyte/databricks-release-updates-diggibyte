This article describes the foundation models that are supported by [Databricks Foundation Model APIs](/aws/en/machine-learning/foundation-model-apis/).

important

Unity Gateway serves models hosted by Databricks and models hosted by third-party providers. Each model's section identifies its hosting arrangement and applicable provider terms. Regardless of where a model is hosted, you are responsible for complying with the provider's applicable terms of use. See [Applicable model terms](/aws/en/machine-learning/model-serving/acceptable-use-models).

note

See [Model availability by region](/aws/en/unity-gateway/model-region-availability) for region availability of these models and the supported feature areas.

You can send query requests to these models through Unity Gateway using their model service names (`system.ai.<model>`), or using the pay-per-token endpoints available in your Databricks workspace. See [Use foundation models](/aws/en/machine-learning/model-serving/score-foundation-models) and [pay-per-token supported models table](/aws/en/machine-learning/foundation-model-apis/#token-foundation-apis) for the names of the model endpoints to use.

In addition to supporting models in pay-per-token mode, Foundation Model APIs also offers provisioned throughput mode. Databricks recommends provisioned throughput for production workloads. This mode supports all models of a model architecture family, including the fine-tuned and custom pre-trained models supported in pay-per-token mode. See [Provisioned throughput Foundation Model APIs](/aws/en/machine-learning/foundation-model-apis/#throughput) for the list of supported architectures.

You can interact with these supported models using the [AI Playground](/aws/en/large-language-models/ai-playground).

For OpenAI, Google Gemini, and Anthropic models, the context window and maximum output tokens match the values published by the respective model provider.

## Google Gemini 4 Argon

important

Customers are responsible for ensuring their compliance with [applicable model terms](/aws/en/machine-learning/model-serving/acceptable-use-models).

This model uses a global endpoint and requires [cross geography routing to be enabled](/aws/en/resources/databricks-geos#cross-geo-processing).

* **Model service name**: `system.ai.databricks-gemini-4-argon`
* **Endpoint name**: `databricks-gemini-4-argon`
* **Supported inputs**: text, image, video, audio

Gemini 4 Argon is a multimodal reasoning model developed and trained by Google. It supports function calling, coding, and complex reasoning over text, images, video, and audio. [Learn more about Gemini 4 Argon](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/guides/gemini-4-argon).

The model is hosted by Databricks. On Azure, it is provided as an ADI Service, hosted and invoiced by Databricks.

For reasoning controls, supported values, and defaults, see [Query reasoning models](/aws/en/machine-learning/model-serving/query-reason-models). Reasoning cannot be disabled.

This model supports pay-per-token workloads. See [supported regions](/aws/en/unity-gateway/model-region-availability).

AI models can make mistakes, misunderstand intent, and hallucinate or give incorrect answers. Databricks recommends customers evaluate their models to ensure they're operating as intended.
