Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page by opting into the **Lakeflow Connect for Anysphere Org** preview. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Anysphere Organization connector in Lakeflow Connect allows you to ingest organization and team data from Anysphere (Cursor) into Databricks.

## Feature availability

| Feature | Availability |
| --- | --- |
| UI-based pipeline authoring | Supported |
| API-based pipeline authoring | Supported |
| Declarative Automation Bundles | Supported |
| Incremental ingestion | Not supported  All tables are refreshed with a full snapshot on each pipeline update. Every table retains daily history via the `snapshot_date` partition column. |
| Unity Catalog governance | Supported |
| Orchestration using Databricks Workflows | Supported |
| SCD type 2 | Not supported  All tables are ingested as full-refresh snapshots with no CDC delete tracking, so SCD type 2 isn't available. |
| API-based column selection and deselection | Supported |
| API-based row filtering | Not supported |
| Automated schema evolution: New and deleted columns | Supported |
| Automated schema evolution: Data type changes | Not supported |
| Automated schema evolution: Column renames | Not supported  Requires a full refresh. |
| Automated schema evolution: New tables | Supported  If you ingest the entire schema. |

## Ingest from Anysphere Organization in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

## Start ingesting from Anysphere Organization

1. **[Configure Anysphere Organization for ingestion](/aws/en/ingestion/lakeflow-connect/anysphere-organization-source-setup)** (Admins) — Set up Anysphere Organization to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/anysphere-organization-connection)** (Admins) — Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/anysphere-organization-pipeline)** (Admins or non-admins) — Select any supported interface and create a pipeline from an existing connection.
