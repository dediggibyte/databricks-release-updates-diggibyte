Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Account admins can manage access to this feature from the account console **Previews** page. See  [Manage account-level previews](/aws/en/admin/workspace-settings/manage-previews#account).

Use these examples to automate skill management. The API represents each skill as a `Skill` resource named `skills/{catalog}.{schema}.{skill}`. To author and publish a skill with an agent, see [Create and share skills](/aws/en/agents/uc-skills/create-share-uc-skills). For privileges and governance, see [Govern skills](/aws/en/ai-gateway/govern-skills). Skills don't have Terraform or Declarative Automation Bundles resources.

## Prerequisites

* Set up a [governed schema for skills](/aws/en/ai-gateway/govern-skills#set-up-a-schema).
* Have the [required permissions for your operation](#api-operations).
* Install and authenticate the client you plan to use. The REST API has no version requirement; each tool and SDK has a minimum version:

  + [Databricks CLI](/aws/en/dev-tools/cli/install): v1.20.0 and above
  + [Python SDK](/aws/en/dev-tools/sdk-python): `databricks-sdk` 0.142.0 and above
  + [Go SDK](/aws/en/dev-tools/sdk-go): `databricks-sdk-go` v0.184.0 and above
  + [Go Modular SDK](https://pkg.go.dev/github.com/databricks/sdk-go/aigateway): `github.com/databricks/sdk-go/aigateway` v0.1.0 and above
  + [Java SDK](/aws/en/dev-tools/sdk-java): `databricks-sdk-java` 0.157.0 and above
  + [JavaScript SDK](https://www.npmjs.com/package/@databricks/sdk-aigateway): `@databricks/sdk-aigateway` 0.23.0 and above

  SDK snippets assume an authenticated workspace client, `w`; Modular SDK snippets assume an authenticated Unity Gateway client, `c` in Go and `client` in JavaScript.

## Create a skill

Creating a skill takes three steps: create the skill, upload its bundle, then finalize it. Until you finalize a skill, its bundle name and description are empty.

### Step 1: Create the skill

Create the skill in a schema. `comment` is the only field you can set. Databricks derives `name`, `bundle_name`, and `description`.

Replace `main.default.my_skill` and `data-team` with your own values.

* REST API
* CLI
* Python SDK
* Go SDK
* Go Modular SDK
* Java SDK
* JS Modular SDK

Send a `POST` to [/api/2.1/unity-catalog/skills](https://docs.databricks.com/api/ai-gateway/v1/create-skill), passing `parent` and `skill_id` as query parameters:

Bash

```
databricks api post \  
  "/api/2.1/unity-catalog/skills?parent=schemas/main.default&skill_id=my_skill" \  
  --json '{"comment": "Team-shared math helper skill"}'
```

Pass the parent schema and skill name, and supply the comment with `--json`:

Bash

```
databricks ai-gateway create-skill schemas/main.default my_skill \  
  --json '{"comment": "Team-shared math helper skill"}'
```

Create and manage a skill with the [Databricks SDK for Python](/aws/en/dev-tools/sdk-python):

Python

```
from databricks.sdk import WorkspaceClient  
from databricks.sdk.service import catalog as c  
  
w = WorkspaceClient()  
  
skill = w.ai_gateway.create_skill(  
    parent="schemas/main.default",  
    skill_id="my_skill",  
    skill=c.Skill(comment="Team-shared math helper skill"),  
)
```

Create and manage a skill with the [Databricks SDK for Go](/aws/en/dev-tools/sdk-go):

Go

```
skill, err := w.AiGateway.CreateSkill(ctx, catalog.CreateSkillRequest{  
	Parent:  "schemas/main.default",  
	SkillId: "my_skill",  
	Skill:   catalog.Skill{Comment: "Team-shared math helper skill"},  
})
```

Create and manage a skill with the [Go Modular SDK](https://pkg.go.dev/github.com/databricks/sdk-go/aigateway). Optional fields are pointers, so the example uses a one-line helper, `func ptr[T any](v T) *T { return &v }`.

Go

```
skill, err := c.CreateSkill(ctx, aigateway.CreateSkillRequest{  
	Parent:  ptr("schemas/main.default"),  
	SkillId: ptr("my_skill"),  
	Skill:   &aigateway.Skill{Comment: ptr("Team-shared math helper skill")},  
})
```

Create and manage a skill with the [Databricks SDK for Java](/aws/en/dev-tools/sdk-java):

Java

```
Skill skill =  
    w.aiGateway()  
        .createSkill(  
            new CreateSkillRequest()  
                .setParent("schemas/main.default")  
                .setSkillId("my_skill")  
                .setSkill(new Skill().setComment("Team-shared math helper skill")));
```

Create and manage a skill with the [JavaScript SDK](https://www.npmjs.com/package/@databricks/sdk-aigateway):

TypeScript

```
const created = await client.createSkill({  
  parent: 'schemas/main.default',  
  skillId: 'my_skill',  
  skill: { comment: 'Team-shared math helper skill' },  
});
```

### Step 2: Upload the bundle

Upload `SKILL.md`, and any supporting files, to the skill's storage path, `/Skills/<catalog>/<schema>/<skill>/`, through the Files API. `SKILL.md` must start with YAML frontmatter that sets `name` and `description`. Save this example as `SKILL.md`:

Markdown

```
---  
name: my-skill  
description: A team-shared skill that helps with basic math.  
---  
  
# My Skill  
  
Step-by-step guidance the agent follows when this skill is loaded.
```

* REST API
* CLI
* Python SDK
* Go SDK
* Go Modular SDK
* Java SDK
* JS Modular SDK

Send a `PUT` to the [Files API](https://docs.databricks.com/api/workspace/files/upload). Set `DATABRICKS_HOST` to your workspace URL, such as `https://my-workspace.cloud.databricks.com`, and `DATABRICKS_TOKEN` to a token. This example passes the token to `curl` on standard input so it doesn't appear in the process list:

Bash

```
curl --request PUT --config - --data-binary @SKILL.md \  
  --header "Content-Type: application/octet-stream" \  
  "${DATABRICKS_HOST}/api/2.0/fs/files/Skills/main/default/my_skill/SKILL.md?overwrite=true" \  
  <<< "header = \"Authorization: Bearer ${DATABRICKS_TOKEN}\""
```

Create the skill's folder, then copy the file into it:

Bash

```
databricks fs mkdir dbfs:/Skills/main/default/my_skill  
databricks fs cp SKILL.md dbfs:/Skills/main/default/my_skill/SKILL.md --overwrite
```

Python

```
with open("SKILL.md", "rb") as f:  
    w.files.upload("/Skills/main/default/my_skill/SKILL.md", f, overwrite=True)
```

Go

```
f, err := os.Open("SKILL.md")  
if err != nil {  
	return err  
}  
defer f.Close()  
  
err = w.Files.Upload(ctx, files.UploadRequest{  
	FilePath:  "/Skills/main/default/my_skill/SKILL.md",  
	Contents:  f,  
	Overwrite: true,  
})
```

The Go Modular SDK doesn't include the Files API. Upload with the [Files SDK for Go](https://pkg.go.dev/github.com/databricks/sdk-go/files) instead:

Go

```
fc, err := files.NewClient(ctx)  
if err != nil {  
	return err  
}  
  
f, err := os.Open("SKILL.md")  
if err != nil {  
	return err  
}  
defer f.Close()  
  
_, err = fc.Upload(ctx, "/Skills/main/default/my_skill/SKILL.md", f, files.WithOverwrite(true))
```

Java

```
try (InputStream contents = Files.newInputStream(Paths.get("SKILL.md"))) {  
  w.files()  
      .upload(  
          new UploadRequest()  
              .setFilePath("/Skills/main/default/my_skill/SKILL.md")  
              .setOverwrite(true)  
              .setContents(contents));  
}
```

The JavaScript Modular SDK doesn't include the Files API, so this example calls the REST endpoint directly. It reads the workspace URL, such as `https://my-workspace.cloud.databricks.com`, and a token from the `DATABRICKS_HOST` and `DATABRICKS_TOKEN` environment variables:

TypeScript

```
import { readFile } from 'node:fs/promises';  
  
const response = await fetch(  
  `${process.env.DATABRICKS_HOST}/api/2.0/fs/files/Skills/main/default/my_skill/SKILL.md?overwrite=true`,  
  {  
    method: 'PUT',  
    headers: {  
      'Content-Type': 'application/octet-stream',  
      Authorization: `Bearer ${process.env.DATABRICKS_TOKEN}`,  
    },  
    body: await readFile('SKILL.md'),  
  },  
);  
if (!response.ok) {  
  throw new Error(`Upload failed: ${response.status} ${response.statusText}`);  
}
```

### Step 3: Finalize the skill

Finalizing reads and validates `SKILL.md`, then sets the skill's `bundle_name` and `description` from its frontmatter. If you change the bundle later, finalize again.

* REST API
* CLI
* Python SDK
* Go SDK
* Go Modular SDK
* Java SDK
* JS Modular SDK

Bash

```
databricks api post "/api/2.1/unity-catalog/skills/main.default.my_skill/finalize" --json '{}'
```

Bash

```
databricks ai-gateway finalize-skill skills/main.default.my_skill
```

Python

```
finalized = w.ai_gateway.finalize_skill(name="skills/main.default.my_skill")  
print(finalized.bundle_name, finalized.description)
```

Go

```
finalized, err := w.AiGateway.FinalizeSkill(ctx, catalog.FinalizeSkillRequest{  
	Name: "skills/main.default.my_skill",  
})
```

Go

```
finalized, err := c.FinalizeSkill(ctx, aigateway.FinalizeSkillRequest{  
	Name: ptr("skills/main.default.my_skill"),  
})
```

Java

```
Skill finalized =  
    w.aiGateway().finalizeSkill(new FinalizeSkillRequest().setName("skills/main.default.my_skill"));
```

TypeScript

```
const finalized = await client.finalizeSkill({ name: 'skills/main.default.my_skill' });
```

## Find a skill

List the skills you can access in a schema, then get a skill's metadata by its resource name.

* REST API
* CLI
* Python SDK

Bash

```
databricks api get "/api/2.1/unity-catalog/skills?parent=schemas/main.default"  
  
databricks api get "/api/2.1/unity-catalog/skills/main.default.my_skill"
```

When the list response includes `next_page_token`, pass it as `page_token` in the next request. Continue until `next_page_token` is absent or empty.

Bash

```
databricks ai-gateway list-skills schemas/main.default  
  
databricks ai-gateway get-skill skills/main.default.my_skill
```

Python

```
for skill in w.ai_gateway.list_skills(parent="schemas/main.default"):  
    print(skill.name)  
  
skill = w.ai_gateway.get_skill(name="skills/main.default.my_skill")
```

The CLI and Python iterator handle pagination for you.

## Grant access

These examples grant `READ VOLUME` on the skill, which lets the principal read the skill and download its bundle. For the other skill privileges, see [Grant access to skills](/aws/en/ai-gateway/govern-skills#grant-access).

* REST API
* CLI
* Python SDK
* Go SDK
* Java SDK

Bash

```
databricks api patch \  
  "/api/2.1/unity-catalog/permissions/skill/main.default.my_skill" \  
  --json '{  
    "changes": [  
      { "principal": "data-team", "add": ["READ_VOLUME"] }  
    ]  
  }'
```

Grant `READ VOLUME` with the Databricks CLI:

Bash

```
databricks grants update skill main.default.my_skill \  
  --json '{"changes": [{"principal": "data-team", "add": ["READ_VOLUME"]}]}'
```

Grant `READ VOLUME` with the [Databricks SDK for Python](/aws/en/dev-tools/sdk-python):

Python

```
from databricks.sdk.service import catalog as c  
  
w.grants.update(  
    securable_type="skill",  
    full_name="main.default.my_skill",  
    changes=[c.PermissionsChange(principal="data-team", add=[c.Privilege.READ_VOLUME])],  
)
```

Grant `READ VOLUME` with the [Databricks SDK for Go](/aws/en/dev-tools/sdk-go):

Go

```
_, err := w.Grants.Update(ctx, catalog.UpdatePermissions{  
	SecurableType: "skill",  
	FullName:      "main.default.my_skill",  
	Changes:
