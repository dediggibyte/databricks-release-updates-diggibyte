Logical replication is native Postgres replication that streams row-level changes between a Lakebase database and another Postgres database. Lakebase can act as a subscriber that receives changes from an external publisher, or as a publisher that sends changes to an external subscriber.

Use logical replication to migrate an existing Postgres database into Lakebase, to replicate between Lakebase databases in different regions, or to stream changes from Lakebase to an external Postgres database.

## Get started

To get started, replicate an external Postgres database into Lakebase. The guide walks through preparing the source, subscribing from Lakebase, and verifying that changes arrive. See [Replicate data into Lakebase](/aws/en/oltp/projects/logical-replication-subscription).

## Logical replication and other data movement methods

Logical replication moves data between Postgres databases. To move Postgres changes into the lakehouse instead, use [Lakebase Change Data Feed](/aws/en/oltp/projects/lakebase-cdf), which writes changes to a Unity Catalog managed Delta table. For a full comparison of the ways to move data in and out of Lakebase, see [Move data in and out of Lakebase](/aws/en/oltp/projects/move-data-in-and-out).

## Limitations

* Logical replication is available on AWS and Azure.
* Logical replication runs over public networking. Private Link is not supported for either direction. The subscriber connection is governed by the account network policy's allowed internet destinations, and the publisher connection is governed by the workspace IP access list.
* Replication between Lakebase databases in the same region is not supported. A subscription from one Lakebase database to another in the same region does not connect. Replication between Lakebase databases in different regions is supported.
* Replication runs on the primary compute, not on read replicas.
* Logical replication copies data, not schema. Create target tables before you start replication. Later schema changes are not replicated.
* Foreign tables are not replicated.
