Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page by opting into the **Anaplan connector** preview. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Anaplan connector in Lakeflow Connect ingests audit trail events and user account records from Anaplan into Databricks.

## Feature availability

| Feature | Availability |
| --- | --- |
| UI-based pipeline authoring | Supported |
| API-based pipeline authoring | Supported |
| Declarative Automation Bundles | Supported |
| Incremental ingestion | Supported  Supported for the `audit_events` table. The connector refreshes the `users` table with a full snapshot on each pipeline update. |
| Unity Catalog governance | Supported |
| Orchestration using Databricks Workflows | Supported |
| API-based column selection and deselection | Supported |
| API-based row filtering | Not supported |
| SCD Type 2 | Not supported |
| Automated schema evolution: New and deleted columns | Supported |
| Automated schema evolution: Data type changes | Not supported |
| Automated schema evolution: Column renames | Not supported  Requires a full refresh. |

## Ingest from Anaplan in three steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/concepts/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Anaplan for ingestion](/aws/en/ingestion/lakeflow-connect/anaplan-source-setup)** (Admins) — Set up Anaplan to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/anaplan-connection)** (Admins) — Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Anaplan.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/anaplan-pipeline)** (Admins or non-admins) — Select any supported interface and create a pipeline from an existing connection.
