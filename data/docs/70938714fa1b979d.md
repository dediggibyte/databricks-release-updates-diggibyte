Beta

This feature is in [Beta](/aws/en/release-notes/release-types). To use it, a workspace admin must turn on **Lakeflow Connect for 1Password Event Logs** from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed 1Password Event Logs connector in Lakeflow Connect ingests Events API data from 1Password into Databricks. Use it to ingest audit events, item usages, and sign-in attempts into Unity Catalog tables.

## Start ingesting from 1Password

1. **[Configure 1Password for ingestion](/aws/en/ingestion/lakeflow-connect/1password-event-logs-source-setup)** (Admins). Set up 1Password to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/1password-event-logs-connection)** (Admins). Create a connection in Catalog Explorer so non-admins can create pipelines.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/1password-event-logs-pipeline)** (Admins or non-admins). Select any supported interface and create a pipeline from an existing connection.
