Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Workspace admins can control access to this feature from the **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

The managed Google Search Console connector in Lakeflow Connect ingests search performance data, site metadata, and sitemap information from Google Search Console into Databricks.

## Ingest from Google Search Console in 3 steps

note

Before starting, review the [Databricks user persona](/aws/en/connect/managed-ingestion), [supported interfaces](/aws/en/ingestion/lakeflow-connect/faq#interfaces), [ingestion frequency](/aws/en/ldp/pipeline-mode), and [common patterns](/aws/en/ingestion/lakeflow-connect/common-patterns).

1. **[Configure Google Search Console for ingestion](/aws/en/ingestion/lakeflow-connect/google-search-console-source-setup)** (Admins): Set up Google Search Console to authenticate with Databricks.
2. **[Create a Unity Catalog connection](/aws/en/ingestion/lakeflow-connect/google-search-console-connection)** (Admins): Create a connection in Catalog Explorer to store credentials for Databricks to authenticate with Google Search Console.
3. **[Create an ingestion pipeline](/aws/en/ingestion/lakeflow-connect/google-search-console-pipeline)** (Admins or non-admins): Select any supported interface and create a pipeline from an existing connection.
