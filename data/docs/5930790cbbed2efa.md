Data Classification detects sensitive data and assigns [system tags](/aws/en/admin/governed-tags/#system-governed-tags) to matching columns. For a mapping of tags to compliance frameworks, see [Compliance framework reference](#compliance-reference). For a full list of tags organized by **global tags** (which apply across all cloud regions) and **regional tags** (which detect data specific to certain countries or regions), see [Global tags](#global-tags) and [Regional tags](#regional-tags).

The following tables show which tags are relevant to common regulatory frameworks. A tag may appear in more than one framework.

* Mexico LFPDPPP
* Swiss FADP
* Israel PPL
* UAE PDPL
