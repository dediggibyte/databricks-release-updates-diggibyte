You can bring any data accessible through Databricks into a visual data prep in Lakeflow Designer.

All data ingestion in Designer starts with the **Source** operator. Add a source from the welcome screen or open a Source operator's configuration pane to choose your data.

## Browse existing tables

On the welcome screen, select a table from **Suggested**, **Favorites**, or **Recently used** to add it as a Source operator. Use the category menu to switch lists, or click **Browse all data** to find another table.

In a Source operator's configuration pane, click **Browse existing** to open the asset selector and browse tables and volumes in Unity Catalog. Use this option when your data is already in Databricks.

You can also select a Unity Catalog metric view as a source. When you select a metric view, select the dimensions and measures to include, and Designer generates the aggregated query.

## Create an external database connection

In an unconfigured **Source** operator, select **Create external database connection** to connect to an external database. Designer creates a Unity Catalog connection and a [foreign catalog](/aws/en/query-federation/database-federation#setup-overview), then opens the catalog so you can select a table.

Creating a new Unity Catalog connection requires the [`CREATE CONNECTION`](/aws/en/data-governance/unity-catalog/access-control/privileges-reference#create-connection) and [`CREATE CATALOG`](/aws/en/data-governance/unity-catalog/access-control/privileges-reference#create-catalog) privileges on the Unity Catalog metastore. To list, grant access to, or drop the connection later, see [Manage connections for Lakehouse Federation](/aws/en/query-federation/connections). To manage the foreign catalog, see [Manage and work with foreign catalogs](/aws/en/query-federation/foreign-catalogs).

Designer supports the following connection types:

* Amazon Redshift
* Azure Synapse
* Databricks
* Google BigQuery
* MySQL
* Oracle
* PostgreSQL
* Salesforce Data Cloud
* Salesforce Data Cloud File Sharing
* Snowflake
* SQL Server
* Teradata

If a data source is not available directly in Designer, check [Lakeflow Connect](/aws/en/ingestion/overview) for a managed connector. Lakeflow Connect supports ingestion from SaaS applications (Salesforce, Workday, HubSpot, and more), databases, cloud storage, and streaming sources. After you ingest data with Lakeflow Connect into a Unity Catalog table, you can use it as a Source in Designer.

## Ingest a folder or volume

Instead of an individual file, the Source operator can target an entire Unity Catalog volume or folder path. Designer detects the format from the files in the folder and loads them into a single table:

* For structured file formats such as CSV, JSON, Excel, and Parquet, Designer reads all of the files and combines their rows into one table.
* For document files such as PDFs, Designer reads each file as a single row, so you get one row per file.

## Drag and drop a file

Drag a file onto the canvas from the workspace file browser or from your local device to automatically create a **Source** operator. For local files, Designer uploads a copy to a Unity Catalog volume for the operator to read.

note

Drag and drop of Excel files requires Excel File Format Support to be enabled. See [Read and stream Excel files](/aws/en/query/formats/excel).

When you add a CSV file, Designer samples the file to detect a comma, tab, semicolon, or pipe delimiter. Check the Source operator's preview to confirm that columns are separated correctly. If the sample is ambiguous or Designer cannot read it, Designer uses the default delimiter. Set **Delimiter** in the Source operator's file options when automatic detection does not match your file.

## Start a visual data prep from files

To start a new visual data prep from one or more files, open the **Visual data prep** page, click the drop-down arrow next to **New**, select **Import file**, and then select **As source**. Upload one or more CSV, JSON, Excel, or PDF files. Designer creates a visual data prep with a Source operator for each file.

## Create a table from a file

Select **Create table from file** in the Source configuration pane to upload a local CSV or Excel file and create a Unity Catalog table from it. Use this option when you want the data persisted as a managed table rather than stored in a volume. Additionally, for large amounts of data, this provides the best performance. Uploaded files are subject to the Unity Catalog volume file size limit. See [Work with files in Unity Catalog volumes](/aws/en/volumes/volume-files).

## Import from Google Drive

To import a file from Google Drive:

1. In the Source configuration pane, select **Import from Google Drive**.
2. Select an existing Unity Catalog connection that has access to Google Drive, or select **Create connection** to create one.
3. Provide the file URL.

For connection requirements and setup instructions, see [Ingest files from Google Drive](/aws/en/ingestion/google-drive).

## Import from SharePoint

To import a file from SharePoint:

1. In the Source configuration pane, select **Import from SharePoint**.
2. Select an existing Unity Catalog connection that has access to your SharePoint site, or select **Create connection** to create one.
3. Provide the **direct file link**.

warning

To get the correct URL, right-click the file in SharePoint, select **Preview**, and copy the URL from the browser address bar. Do not use a sharing link.

For connection requirements and setup instructions, see [Ingest files from SharePoint](/aws/en/ingestion/sharepoint).
