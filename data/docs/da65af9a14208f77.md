**Applies to:**  Databricks Runtime 18.2 and above

IP functions operate on [IPv4 and IPv6 addresses](https://en.wikipedia.org/wiki/IP_address) and [CIDR blocks](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing) represented as `STRING` or `BINARY` values.

## Import Databricks functions to get IP functions (Databricks Runtime)

To import IP functions for Python or Scala in notebooks, use the following commands:

* Python
* Scala

Python

```
from pyspark.databricks.sql import functions as dbf
```

Scala

```
import com.databricks.sql.functions._
```

## List of IP functions

| Function | Description |
| --- | --- |
| [ip\_as\_binary(ip\_or\_cidr)](/aws/en/sql/language-manual/functions/ip_as_binary) | Returns the canonical binary representation of an IP address or CIDR block. |
| [ip\_as\_string(ip\_or\_cidr)](/aws/en/sql/language-manual/functions/ip_as_string) | Returns the canonical string representation of an IP address or CIDR block. |
| [ip\_cidr(cidr)](/aws/en/sql/language-manual/functions/ip_cidr) | Returns the canonical representation of an IPv4 or IPv6 CIDR block. |
| [ip\_cidr\_contains(cidr, needle)](/aws/en/sql/language-manual/functions/ip_cidr_contains) | Returns `TRUE` if an IP address or CIDR block is contained within another CIDR block. |
| [ip\_host(ip)](/aws/en/sql/language-manual/functions/ip_host) | Returns the canonical representation of an IPv4 or IPv6 address. |
| [ip\_network(cidr)](/aws/en/sql/language-manual/functions/ip_network) | Returns the network portion of a CIDR block in its canonical form. |
| [ip\_network\_first(cidr)](/aws/en/sql/language-manual/functions/ip_network_first) | Alias for `ip_network`. |
| [ip\_network\_last(cidr)](/aws/en/sql/language-manual/functions/ip_network_last) | Returns the last address of a CIDR block in its canonical form. |
| [ip\_prefix\_length(cidr)](/aws/en/sql/language-manual/functions/ip_prefix_length) | Returns the prefix length of a CIDR block. |
| [ip\_version(ip\_or\_cidr)](/aws/en/sql/language-manual/functions/ip_version) | Returns the IP version (4 or 6) from an IP address or CIDR block. |
| [try\_ip\_as\_binary(ip\_or\_cidr)](/aws/en/sql/language-manual/functions/try_ip_as_binary) | Returns the canonical binary representation of an IP address or CIDR block, or `NULL` if invalid. |
| [try\_ip\_as\_string(ip\_or\_cidr)](/aws/en/sql/language-manual/functions/try_ip_as_string) | Returns the canonical string representation of an IP address or CIDR block, or `NULL` if invalid. |
| [try\_ip\_cidr(cidr)](/aws/en/sql/language-manual/functions/try_ip_cidr) | Returns the canonical representation of an IPv4 or IPv6 CIDR block, or `NULL` if invalid. |
| [try\_ip\_host(ip)](/aws/en/sql/language-manual/functions/try_ip_host) | Returns the canonical representation of an IPv4 or IPv6 address, or `NULL` if invalid. |
