In Governance Hub, the **Tags** page provides a centralized view of how tags are applied across your account. It summarizes governed tag usage, shows recent tag assignments and their sources, and recommends fixes for invalid tag values and important assets that are missing tags. Use this page to monitor tag coverage and consistency so that you can rely on tags for governance, access policies, and cost attribution.

Beta

This feature is in [Beta](/aws/en/release-notes/release-types). Account admins can enable it from the account console **Previews** page. See [Manage Databricks previews](/aws/en/admin/workspace-settings/manage-previews).

## How the Tags page works

The Tags page draws on account-wide metadata to report tag coverage and usage across both Unity Catalog and workspace objects. The **Governed Tags** and **Domains** tiles always reflect the whole account. The remaining tiles, along with the Recent tag assignments and Tag recommendations views, reflect the [scope](#change-the-scope) you select. Actions that you take from the Tags page, such as managing a governed tag, respect your existing permissions.

Access to the Tags page is limited to account admins during Beta.

## Change the scope

The data displayed on the Tags page depends on the chosen *scope*, which you can select in the top right corner. For account admins, this is set to  **Account** by default. Select a different scope, such as an individual workspace, to update the page to reflect that scope. The **Governed Tags** and **Domains** tiles remain account-scoped regardless of your selection. For more information about who can view each scope, see [Access and permissions](/aws/en/admin/governance-hub/#access-and-permissions).

## View recent tag assignments

The **Recent tag assignments** tile tracks the number of tag assignments made in the chosen scope over the last 30 days. Click **Review Tag Assignments** for details, which opens the **Tag Assignments** page.

The Tag Assignments page contains a bar chart of tag assignments over the last 30 days, stacked by the source of each assignment, such as a user, data classification, or tag propagation. Below the chart, a table lists recently tagged assets with the asset name, type, tag assignment, the date it was assigned, who assigned it, and the workspace it was assigned from. You can filter the chart and table by workspace, source, asset type, and tag key and value.

You can review recent tag assignments across asset types, such as catalogs, schemas, tables, columns, functions, models, volumes, external metadata, notebooks, dashboards, Genie, agents, and apps.

When there is an unusual spike in a category of tag assignments, such as PII, deprecated, or certified tags, the page adds a quick-filter chip. Click a chip to filter the chart and table to the week that triggered the spike so that you can review the change.

## Review governed tag usage

The **Governed Tags** and **Governed tag usage** tiles track your governed tags and how widely they are applied. The **Governed tag usage** tile ranks governed tags by the number of assets they are assigned to, so that you can see which tags are most used in the chosen scope.

To manage governed tags or review the full ranked list, click **Manage** or **Review Popular Tags**. Both open the **Governed Tags** page, where you can create, edit, and delete governed tags and manage permissions. For more information about creating and managing governed tags, see [Governed tags](/aws/en/admin/governed-tags/).

## Review tag recommendations

The **Tag recommendations** pane suggests assets to fix or tag across the account. Recommendations are read-only. Each recommendation lists the affected assets and their recent usage over the last 30 days. Click **Review** to see the full list of findings and open an asset's details, from which you can open the asset in a workspace.

The pane can include the following recommendations:

* **Tables containing invalid tag values**: Tables assigned a tag value that is not in the governed tag's allowed values. Review them to correct or remove the invalid assignments.
* **Missing tags on popular dashboards**: Your most-viewed dashboards that are not assigned any governed tag.
* **Missing tags on popular tables**: Your most-queried tables that are not assigned any governed tag. This recommendation opens the **Data recommendations** page. See [Improve data governance with recommendations](/aws/en/admin/governance-hub/data#data-recommendations).

## Limitations

The Tags page has the following limitations during Beta:

* Access is limited to account admins. Support for additional roles may be added in the future.
* Recent tag assignment data covers the last 30 days only.
* The **Governed tag usage** tile and its **Review Popular Tags** button open the existing **Governed Tags** management page rather than a dedicated view on the Tags page.
