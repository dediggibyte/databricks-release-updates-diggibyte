The map visualizations display results on a geographic map. The query result set must include the appropriate geographic data:

* **Choropleth**: Colors geographic localities, such as countries or states, according to the aggregate values of each key column. The query must return geographic locations by name (see [Region lookup tables](#region-lookup-tables) for supported names) or as a [GEOMETRY](/aws/en/sql/language-manual/data-types/geometry-type) or [GEOGRAPHY](/aws/en/sql/language-manual/data-types/geography-type) column. For an example, see [Choropleth map](/aws/en/dashboards/manage/visualizations/types#choropleth).
* **Point map**: Places a marker at a set of coordinates on the map. The query result must return latitude and longitude pairs or a [GEOMETRY](/aws/en/sql/language-manual/data-types/geometry-type) or [GEOGRAPHY](/aws/en/sql/language-manual/data-types/geography-type) column. For an example, see [Point map](/aws/en/dashboards/manage/visualizations/types#point-map).
* **Path map**: Draws lines on the map from a [GEOMETRY](/aws/en/sql/language-manual/data-types/geometry-type) or [GEOGRAPHY](/aws/en/sql/language-manual/data-types/geography-type) line column, with one line per row, or by connecting a sequence of points into a line. Use it for routes, transit lines, rivers, borders, or point-by-point trajectories such as GPS tracks. For an example, see [Path map](/aws/en/dashboards/manage/visualizations/types#path-map).

You can also render shapes from a [GEOMETRY](/aws/en/sql/language-manual/data-types/geometry-type) or [GEOGRAPHY](/aws/en/sql/language-manual/data-types/geography-type) column instead of relying on predefined administrative boundaries or separate latitude and longitude columns. See [Custom geographic data](#custom-geographic-data).

### Region

The **Region** setting tells the map how to interpret the location values in your data. Choose the format that matches your data. Databricks supports administrative boundaries, postal codes, US Census statistical areas (CSA and CBSA), US legislative districts, and EU NUTS regions. For the levels available under each format, along with the names, abbreviations, or codes they accept, see [Region lookup tables](#region-lookup-tables).

If a value in your location column doesn't match the selected format, no data is shown for that region.

Alternatively, select **Custom geometry** to render region boundaries directly from a [GEOMETRY](/aws/en/sql/language-manual/data-types/geometry-type) or [GEOGRAPHY](/aws/en/sql/language-manual/data-types/geography-type) column in your data. See [Custom geographic data](#custom-geographic-data).

### Coordinates

For ungrouped data, click the color swatch to change the point colors shown on the map. To apply a grouping strategy, click  in the **Color** section of the visualization editor. You can adjust the automatically assigned colors by clicking the color swatch next to each group label in the editor.

Click  in the **Size** section to choose a field that reflects quantity. This lets you display dots of varying sizes based on the data value.
